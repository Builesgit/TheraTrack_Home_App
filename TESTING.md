# TESTING

Checklist manual recomendado para TheraTrack Home.

- Registro profesional nuevo -> queda pendiente -> no puede acceder.
- Bootstrap o aprobación de profesional.
- Login profesional aprobado.
- Registro paciente con código -> queda pendiente -> no puede acceder.
- Profesional crea ficha clínica y aprueba paciente.
- Paciente aprobado accede dashboard.
- Paciente reporta síntomas.
- Historial muestra gráfica.
- Insertar alerta manual en Supabase y abrir app paciente -> aparece notificación local.
- Hospital revisa alerta desde BottomSheet.
- Hospital genera PDF y se abre.
- Hospital exporta CSV y se puede compartir.
- Paciente cambia idioma.
- Paciente desactiva recomendaciones y deja de recibirlas.
- Profesional cambia contraseña.
- Asistencia abre teléfono/email/enlaces.
